## About me

Third-year CSE student at TKM College of Engineering, Kerala.
I build developer tools, ML systems, and full-stack applications —
usually because I personally hit the problem first.

Currently building **[Crespo](https://github.com/hrudulmmn/crespo)** —
an AST-based repository compression tool that gives AI
the architectural blueprint of a codebase instead of raw source files.

- 🎓 B.Tech CSE @ TKMCE · 2024–2028 · **9.63 CGPA**
- 🔨 Building in public — developer tooling + AI + full stack
- 🌱 Learning DSA consistently · NeetCode 150 in progress
- 📍 Kerala, India
